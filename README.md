# CPURacer

在 Windows 任务管理器（taskmgr）的 CPU 性能折线图上玩赛车的 meta 小游戏。

灵感来自 [copy-dialog-lunar-lander](https://github.com/Sanakan8472/copy-dialog-lunar-lander)：把系统原生 UI 当成游戏场地。

## 玩法构想

- **赛道**：任务管理器「性能 → CPU」实时折线图
- **车辆**：沿蓝色 CPU 利用率曲线行驶
- **场景**：工作时 CPU 波动形成起伏的“赛道”

## 参考
