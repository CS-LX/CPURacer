# M4 — 玩家壳 + 降级与发布

**状态：** 待实施（合入原「降级/发布」与玩家 UX，不单插阶段）  
**前置：** M3 可玩验收通过；不挖 M2.6.2 承重墙  

## 为何合入 M4（而非 M3.5）

相对 lunar-lander 的缺口主要在 **默认 Play 画面、玩法循环、开局提示**，与「可分享交付」同属发布面；降级提示、管理员键位提示也是玩家路径的一部分。单插阶段只会拆薄验收，故扩 M4 一并做。

## 对照 lunar-lander 的差距（自查摘要）

| 维度 | lunar-lander | CPURacer（M3 后） |
|---|---|---|
| 默认画面 | 玩家向；Tab 才 debug | 橙拟合线 / 红框 / `cap=` 默认进对局 |
| 开局 | 点图 “Click here to play” | 跟踪 → 托盘「开始比赛」 |
| 循环 | 燃料、落点、得分、成败文案 | 出界死 + Space；无目标/分 |
| 托盘 | 难度 / 退出为主 | 跟踪后端与调试项并列 |

粗估：玩法骨架 ~40–50%；玩家 UX ~15–25% 到可分享笑话完成度。

## 硬规则

- Play 默认：**关**拟合线、**关**调试描边；诊断只进 Advanced / Tab  
- 有车时不得因 `_carPose != null` 强制画红框诊断层  
- 物理仍旁路 RaceHost；不改 `TickExternalFrame` 语义
