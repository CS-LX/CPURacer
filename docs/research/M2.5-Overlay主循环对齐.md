# M2.5 — External Overlay 主循环对齐 copy-dialog

**日期：** 2026-08-08  
**范围：** 仅 External；Child / SetParent **未改**；M3 仍在 git stash。

> **已被 M2.6 取代：** WPF External 在点击/焦点与 layered 重绘上未达到 M3 门禁；现迁移到[原生 External Overlay](M2.6-原生ExternalOverlay迁移.md)。本文保留为失败路径与决策记录。

## 原则澄清

copy-dialog 的 Overlay **没有毒**，玩法同属「钉系统图 + 透明 Topmost + 每帧跟」。  
我们**可以且应该复刻**其帧循环与显隐规则。

| 层 | 谁负责 | 说明 |
|---|---|---|
| 发现图表 HWND / CPU 页 | TrackNative（C++） | **加速发现**，不替代 Overlay 循环 |
| 每帧：几何 / 前台 / 捕获 / DrawingGroup | C# Overlay（对齐 copy-dialog） | 稳健性核心在这里 |
| Child SetParent | 另路径，本里程碑不改 | — |

先前把「未对齐」说成「C++ 限制了复刻」是错的：C++ 只喂 `ChartHwnd`，不阻止复刻 `TrackChartView`。

## 对照

| | copy-dialog | CPURacer External |
|---|---|---|
| 时钟 | `CompositionTarget.Rendering` | 同左 |
| 每帧 | 几何 + 前台 + 捕获 + `DrawingGroup` | 同左（`TickExternalFrame`） |
| 藏窗 | `Top=20000`，仍 `Show()` | 同左 |
| 前台 | `isActive` + chart 祖先链；多 Overlay 用 active 闩 | 只跟 Taskmgr 祖先链；External 不获取焦点 |
| 点击 | Overlay 抢焦点；作者记录偶发要点多次 | `WM_MOUSEACTIVATE → MA_NOACTIVATE`，并保持 Taskmgr 前台 |
| 失焦捕获 | chart 可见仍捕获 | 同左（`cap=warm`） |
| 发现 | UIA | TrackNative 加速；C++ 区分扫描瞬断与明确非 CPU 页，前者保留有效 HWND、后者立即隐藏 |
| DPI | 跨屏已知会抽搐 | 每帧 `GetDpiForWindow`，比参考实现更稳健 |
| 单帧异常 | 捕获后 Sleep | 帧级隔离、保留上一 backing frame、下一帧自动重试 |

## 手工验收（External + 普通权限）

| # | 步骤 | 期望 |
|---|---|---|
| 1 | 静止跟踪 CPU | 红框/橙线稳定 |
| 2 | 拖动 Taskmgr | 跟随无明显闪 |
| 3 | 拖完 / 缩放后，**第一次**点 Overlay | Taskmgr 保持前台，Overlay 不藏 |
| 4 | 点其它应用 | 移出屏；托盘可见 `cap=warm` |
| 5 | 切非 CPU 页 | 隐藏/清线 |
