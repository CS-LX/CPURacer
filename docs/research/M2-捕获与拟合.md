# M2 — 捕获与蓝线拟合

**状态：** ✅ 本机手工拟合验收通过（浅/深主题 2026-08-08）；External 可录屏 WGC 路径 ✅（2026-08-10）：自研会话 + ExtendedFrame 裁 ROI、最大化贴合、无黄边、截图可见 Overlay。

## 选型

| 路径 | 用途 |
|---|---|
| **Windows Graphics Capture（Taskmgr window → CPU ROI）** | **External 主路径**：含合成蓝线、不含独立顶层 Overlay |
| Screen ROI（桌面 DC `BitBlt`） | 旧 Child / SetParent 兼容路径 |
| `CvChartWindow` BitBlt | **禁止**作蓝线来源（仅网格） |

External 捕获使用自研 WGC 会话只读取 Taskmgr 主窗口，再按 **屏幕坐标相对
`DWMWA_EXTENDED_FRAME_BOUNDS`** 裁 CPU ROI（本机实测 `GraphicsCaptureItem.Size`
与 ExtendedFrame 一致，图表顶边落在 `chart.Top - ext.Top`；勿走会钳负 Y 的
client 映射）。独立顶层 Overlay 不进入地形帧，因此移除 `WDA_EXCLUDEFROMCAPTURE`
后，系统截图 / OBS 显示捕获仍能看到车与提示。旧 Child 路径继续使用桌面
`BitBlt(SRCCOPY)` + WDA；两条路径均**禁止**逐帧藏窗（会导致闪烁）。
启动会话前请求 borderless 并设置 `IsBorderRequired=false`（非打包应用若未获授权，
黄边仍可能保留；见 Win11「隐私 > 屏幕截图和应用」）。

## 高度场

- 类：`HeightFieldExtractor` + `PlotInset.DefaultWin11Cpu`（ROI 已是图矩形，默认仅守边 L4 T4 R4 B4）
- 每列寻找高饱和蓝色描边脊；缺失列由邻接轮廓插值
- 整帧可信覆盖率不足时跳过并保留上一条可靠轮廓，禁止固定高度回退
- 仅清理单列 impulse，再做轻度横向平滑（半径 1）
- 捕获刷新约 30Hz（33ms）

## 运行（验收基线）

1. **普通权限** + 托盘跟随方式 **外部 Overlay**
2. Taskmgr → 性能 → CPU，开始跟踪，开 **调试拟合线**
3. 状态含 `cap=wgc-ok cols=…`；橙色折线应贴蓝线，且不应随时间自行爬升

## 已知失败模式

- WGC 黄边：已在 `StartCapture` 前设 `IsBorderRequired=false` 并请求 borderless；本机 2026-08-10 验收无黄边。若用户拒绝授权，或 Win11「隐私 > 屏幕截图和应用」未允许关闭边框，系统仍可能画指示边
- 最大化偏移（已修）：曾因第三方库 client 坐标把负原点钳成 0；现用 ExtendedFrame 屏幕坐标自裁
- Child Overlay 仍使用 `WDA_EXCLUDEFROMCAPTURE`；可录屏保证以默认 External 为准
- 管理员 / 子窗跟随：见 M1.5 完整性记录；M2 拟合以普通+外部为准
- inset 不准时线整体上/下偏移 → 调 `PlotInset.DefaultWin11Cpu`
- 多显示器 DPI 混用时 ROI 可能错位（PerMonitorV2 进程仍建议单屏验收）
