**状态：** ✅ 可玩验收通过（2026-08-09）；帧编排定案更新 ✅（2026-08-17，PR #2 手工验收）  
**物理库：** `Box2D.NetStandard` 1.0.4（Box2DX API）

## 判断：承重墙是什么

M2.6.2 用代价换来的稳态是：**Topmost + 同 PID 前台显隐、点击穿透、热路径不每帧改托盘**。  
「独立 Dispatcher 时钟」曾是达到该稳态的手段；**2026-08-17** 合入社区 PR 后改为 **RaceHost 单 60Hz 循环**（External 进给 → 物理 → `RenderNow`），本机验收：**跳变延迟明显下降，托盘焦点往返无回归** → **保留并钟**。

| 禁止（挖墙） | 允许 |
|---|---|
| 热路径里每帧 `SyncRaceMenu` / 改托盘 | 状态**边沿**才更新托盘 |
| 改 `PlaceAndShow` / 前台显隐 / Z 序语义当赛季补丁 | Overlay 只加只读出口 + 只绘姿态入口 |
| Overlay 持有或引用 `RaceSim` | Overlay 只吃 `CarState?` 快照 |
| 开赛默认关掉拟合线 | 可选，默认保持 M2 视觉 |

## 数据流（2026-08-17 定案）

```text
App RaceHost（单一 16ms DispatcherTimer）
  ├─ TickExternalFrameSafe：WGC 捕获 + 提取 + SetTerrain + 放置/显隐
  ├─ RaceSim.Step / 输入
  └─ NativeExternalOverlay.RenderNow（同帧地形 + 车姿）
```

Child 路径仍用独立捕获时钟；`SetCarPose` 只重建 DrawingGroup。

## 摄像机卷轴（已定：真世界续铺 + 视口投影）

折线视口 = 固定屏幕窗口。蓝线左滚 ≡ 视口在世界中右移（`scrollOriginPx`）。  
历史采样 Y 基本不变，只随卷轴左移、右侧进新点——物理侧据此：

- 高度场仍是摄像机空间输入；相关估 `shiftPx` 后：`scrollOriginPx += shift`，只把**右缘新列** append 进世界折线
- 车身在世界坐标里只受物理力，**不再**每帧 `SetXForm` / SoftNudge 跟卷轴
- 绘制：`frameX = insetLeft + worldXPx - scrollOriginPx`

## 物理定案（Hill Climb 对齐）

| 项 | 做法 |
|---|---|
| 单位 | `PixelsPerMeter=60` 米制世界，重力 `-10`；`GetCarState` 视口投影回像素 |
| 步长 | accumulator + 固定 `1/60`，每帧最多 4 子步 |
| 地形 | 世界折线 seed + 右缘 append / 左侧 trim；仅几何变化时重建 edge；不抬车、不挪车 |
| 车 | 硬轴：`RevoluteJoint` + 轮电机（Feronato / Box2D3 wireframe）；无悬挂弹簧 |
| 驱动 | 无级 `pedal∈[-1,1]`：W 加油、S 减油（过 0 倒车）；`MotorSpeed`∝pedal |
| 输入 | Taskmgr 高完整性前台时需管理员运行（UIPI）；HUD `keys=` / `pedal=` 区分键与物理 |
