# M3 — 物理赛车（非侵入）

**状态：** 正在实施 / 地基为 **M2.6.2**（不得挖承重墙）  
**物理库：** `Box2D.NetStandard` 1.0.4（Box2DX API）

## 判断：该不该侵入 M2？

**不该。** M2.6.2 已用代价换来稳态：独立 Dispatcher 帧时钟、同 PID 前台判定、Topmost + 非目标前台 Hide。上一版把 `RaceSim` / 托盘同步塞进 Present 热路径后，托盘往返会把 Overlay 压到 Taskmgr 下面——这是装修砸承重墙的实证。

| 禁止（挖墙） | 允许（薄缝） |
|---|---|
| 在 `TickExternalFrame` 内跑物理 / `beforeRender` | App **旁路** `DispatcherTimer` 独立 `Step` |
| 热路径里每帧 `SyncRaceMenu` / 改托盘 | 状态**边沿**才更新托盘 |
| 改 `PlaceAndShow` / 前台显隐 / Z 序语义当赛季补丁 | Overlay 只加只读出口 + 只绘姿态入口 |
| Overlay 持有或引用 `RaceSim` | Overlay 只吃 `CarState?` 快照 |
| 开赛默认关掉拟合线 | 可选，默认保持 M2 视觉 |

## 数据流

```text
TrackNative → NativeExternalOverlay.TickExternalFrame
                    │
                    ├─ HeightFieldUpdated / CurrentHeightField ──► App RaceHost
                    │                                              │
                    │                                              ├─ RaceSim.SetTerrain / Step
                    │                                              └─ SetCarPose(CarState?)
                    │                                                       │
                    └─ RenderFrame ←──────────── _carPose ──────────────────┘
                       （几何/捕获/显隐逻辑不变）
```

Child 路径同理：`SetHeightField` 发事件；`SetCarPose` 只重建 DrawingGroup。

## 实施切片

1. **M3-A 薄契约**：`CurrentHeightField`、`HeightFieldUpdated`、`SetCarPose` + 画车；零行为变化当 pose=null  
2. **M3-B RaceHost**：独立 16ms `DispatcherTimer`；输入 / Step / 边沿菜单；**禁止**挂进 `OnExternalTick`  
3. **M3-C 可玩验收**：贴地、翻车失控、出视口死亡、Space/托盘重开  

## 摄像机卷轴（已定：真世界续铺 + 视口投影）

折线视口 = 固定屏幕窗口。蓝线左滚 ≡ 视口在世界中右移（`scrollOriginPx`）。  
历史采样 Y 基本不变，只随卷轴左移、右侧进新点——物理侧据此：

- 高度场仍是摄像机空间输入；相关估 `shiftPx` 后：`scrollOriginPx += shift`，只把**右缘新列** append 进世界折线
- 车身在世界坐标里只受物理力，**不再**每帧 `SetXForm` / SoftNudge 跟卷轴
- 绘制：`frameX = insetLeft + worldXPx - scrollOriginPx`

## 物理定案（Hill Climb 对齐）

| 项 | 做法 |
|---|---|
| 单位 | `PixelsPerMeter=60` 米制世界，重力 `-10`；`GetCarState` 视口投影回像素 |
| 步长 | accumulator + 固定 `1/60`，每帧最多 4 子步 |
| 地形 | 世界折线 seed + 右缘 append / 左侧 trim；仅几何变化时重建 edge；不抬车、不挪车 |
| 车 | 硬轴：`RevoluteJoint` + 轮电机（Feronato / Box2D3 wireframe）；无悬挂弹簧 |
| 驱动 | `SetMotorSpeed` / `maxMotorTorque`；后轮主驱，松开极小空闲扭矩 |
| 输入 | Taskmgr 高完整性前台时需管理员运行（UIPI）；HUD `keys=` 区分键/物理 |

### 手工验收（管理员 + Taskmgr 前台）

1. 静止贴地，无明显上下弹  
2. 松油门相对蓝线缓慢左移（镜头右移）  
3. W 能明显向右顶住/超过卷轴  
4. S 减速；出左边界死亡  
5. HUD `keys=` 仍可区分键与物理
